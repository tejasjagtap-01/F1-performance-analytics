# 🏎️ Data Source Documentation

This repository utilizes a multi-table, historical motorsport dataset to analyze Formula 1 championship trends, telemetry summaries, race craft delta, and team performance metrics.

## 🔗 Original Source Link
* **Dataset Sourced From:** Kaggle
* **Direct Download Link:** https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020
* **Maintained By:** Vopani (Rohan Rao)
* **Original Data Compiler:** [Ergast Developer API](http://ergast.com/mrd/)
* **Licensing:** CC0: Public Domain

## 📦 Dataset Properties & Footprint
* **Raw File Format:** Relational CSVs (14 separate flat CSV files)
* **Compressed File Size:** ~7 MB (.zip archive)
* **Uncompressed Storage Footprint:** ~50–60 MB
* **Temporal Coverage:** 1950 to 2024 Championship Seasons
* **Key Relational Tables:** `circuits.csv`, `constructor_results.csv`, `constructor_standings.csv`, `constructors.csv`, `driver_standings.csv`, `drivers.csv`, `lap_times.csv`, `pit_stops.csv`, `qualifying.csv`, `races.csv`, `results.csv`, `seasons.csv`, `sprint_results.csv`, `status.csv`
